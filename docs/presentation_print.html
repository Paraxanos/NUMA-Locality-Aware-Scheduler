PART 01 PROBLEM STATEMENT & BASE SCHEDULER FOUNDATIONS
The Problem & Base Mechanism: Locality vs. Load Balance
Why uniform work-stealing fails on NUMA/Manycore — and where Muddukrishna et al. (2015) leaves gaps
The Main Problem Statement
NUMA & Manycore
  • The Hardware Shift: Accessing remote NUMA RAM (240–340 cyc vs 40 cyc) or far mesh tiles (66 cyc vs 10 cyc) is 4×–8.5× slower than local accesses.
  • Default Runtime Flaw: Classic work-stealing (ws) schedules purely for core occupancy, dragging cache lines across buses and saturating interconnects.
  • Base Paper Fix & Backfire: Locality-aware dealing (la) places tasks near data, winning on regular Map (−45.3% comm), but starving 7 nodes on SparseLU (+19.2% slower!).
  • Our Objective: Jointly optimize memory locality, queue occupancy, and interconnect reach across MIR (Opteron NUMA) & TILEPro64 without adding hot-path lock contention.
Base Benchmarks (OpenMP Tasks via MIR): Map (48 tasks) · Matmul (256) · Reduction (48) · Jacobi 2D (64) · SparseLU (204 irregular DAG tasks)
Base Scheduler (Algorithm 3) & Memory Policies
MIR Baseline
// Base Paper Task Scheduling Pipeline (push_numa / pop_numa):
1. Footprint D[N]: Estimate bytes read per node/tile via depend/API
2. Significance Gate: If sum(D) > LLC/Cores (64KB) → Deal to argmin(cost)
3. Gap Here: Placement ignores queue length; no check if target overloaded!
4. Steal Loop: Walk nearby queues within fixed vicinity radius & pop tail
  • Coarse Distribution: Entire array/chunk homed on one node/tile → huge locality win if threads stay home, catastrophic hot-spot if queues overflow.
  • Fine Distribution: Cache lines (64 B) or OS pages (4 KB) interleaved round-robin → spreads load uniformly, but loses local hit rate (~52 cyc base on mesh).
  • HAL-Sim Substrate (KTH SLIT): 8 nodes, 24 cores; SLIT latencies 10 (local), 16 (1-hop), 22 (2-hop cross-parity).
Key Conflict: Locality wants tasks pinned; Load Balance wants free stealing.
From Base Paper to NOVA: Muddukrishna et al. left load feedback, task-level stealing, adaptive radius, and 2D mesh blocking unaddressed—defining our 10 architectural hotspots.
